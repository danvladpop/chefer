# Wave 1 — Safety, gym, plan, entry, tracking, data (6 lanes)

Source of truth: `docs/persona-study-2026-09/synthesis/04-technical-plan.md` (rev 2, final) §5.1–5.15e, §6, §7.2–7.3.
For a task's full file list and design rationale, read the exact pointer in §4 below — this brief gives one-line
descriptions and the files each lane **owns**, not the complete per-task file lists.

## 1. Goal

Ship the six biggest UX items end to end: one safety filter everywhere, the gym engine fixes + chaos-tolerant
training, plan-shape/week-mechanics you can trust, welcome/consent/wellness-guardrail entry flows, fast food logging
with own targets and a change-notice log, and consented mobile analytics. User-visible outcome: allergy/diet/dislike
filtering is real and shown everywhere; the gym engine's progression bugs are fixed; Plan/Shop never show the wrong
week; sign-up has proper consent; logging food takes ≤ 2 taps and mistakes are fixable; targets can be self-set and
never change silently.

## 2. Prerequisites

Wave 0 (`integrate/ux-now-w0`) merged to `master` and deployed — schema S1–S17, router stubs, flags/API-level
header, kit components, nav, and the five hotfixes must all be live before any wave-1 lane branches.

**Blocked-by-owner-decision:**

## 5. Acceptance criteria (condensed, by UX item — IDs from 03)

- **UX-01** (L-SAFE): AC1–2 read-back + recogniser outcomes; AC3–6 no unsafe recipe in a generated week / for a
  dislike / in Replace / from `whatCanIMake`; AC7 editing a vegetarian recipe keeps the tag; AC9 migration card
  over-blocks until confirmed; AC10 report hides the recipe; AC13 Replace rejects unsafe ids; AC14 no coeliac recipe
  with spelt/seitan/semolina/malt/couscous, no bare `gluten-free` tag on a label-dependent recipe.
- **UX-02** (L-SAFE): AC1 Checked element shown only when rules exist; AC3 conflict replaces Checked; AC4 copy lint
  passes; AC7 `Filtered for …` line with correct hidden count; AC8 coeliac sees the label-caveat + `Buy certified
gluten-free` line.
- **UX-05** (L-GYM): AC1 progression worked examples (bench/deadlift) give the right next target; AC2 no "today" in
  a `when:'next'` sentence; AC4 5 chosen days → weekly goal 5; AC6 40→150 kg in ≤5 taps; AC8 chart labels never
  clipped; AC9 typed reps propagate without collapsing the card; AC11 Maestro gym flows green, WhySheet/set-row
  snapshots empty (protect D1/D2).
- **UX-36** (L-GYM): AC1 settings reachable from 4 entry points; AC2 reminder in ≤3 taps, quiet-nudge respects
  pauses; AC3 Save-for-later resumes 24h, carry-over prepends `From last time`; AC4 no `0-week streak`; AC5 Skip has
  Undo; AC6 History lists sessions, sets numbered from 1.
- **UX-07** (L-PLAN): AC1 shaped generation (slots/days/time-cap/servings) produces exactly the right meals; AC2
  Shop list matches; AC3 empty-week button names the shape; AC4 pinned picks survive Regenerate; AC7 untouched
  profile ⇒ unchanged plan (backward compat).
- **UX-08** (L-PLAN): AC1 `defaultWeekOffset` correct incl. DST; AC2/AC9 week-matched Shop/Plan/Today (B-13, tested
  again here); AC3 Regenerate asks + keeps + Undo restores exactly; AC4 post-upgrade actions actually act (B-09);
  AC5 Replace keeps portion + Undo; AC10 Replace picker no dupes/no replaced meal (B-50).
- **UX-22** (L-ENTRY/L-SAFE/L-TRACK): AC1 conditions recognized, nothing saved; AC2 chat header always shows the AI
  disclaimer; AC3 prompt snapshot has the guardrail; AC4 health/safety-topic footers render; AC5 goal/metrics
  disclaimer visible at 1.8× text; AC7 no "add a snack" for Lose.
- **UX-25** (L-ENTRY): AC1 fresh install → Welcome, never "Welcome back"; AC2 after one sign-in, sign-out → "Welcome
  back".
- **UX-39** (L-ENTRY/L-DATA): AC1 registration blocked without ticking Terms/Privacy; AC2 new accounts: digests +
