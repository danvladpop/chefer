# Wave 3 — Food follows training + share, health consent (2 lanes)

Source of truth: `docs/persona-study-2026-09/synthesis/04-technical-plan.md` (rev 2, final) §5.6, §5.11, §5.15
(health-consent parts), §6, §7.2–7.3.

## 1. Goal

Finish "food follows training" (weekday kinds, bumps, plan markers, refuel placements), let people share the list
and dinners, and close the health-consent loop end to end (consent sheet on every health save path, server-side
enforcement, withdrawal, the AI-generated chip, an evidence trail). User-visible outcome: Plan shows run/long-run
glyphs and carb-led bumps, not just lift days; a `Share` button sends the list or dinners as clean text; every health
save (allergies, goal, metrics, weight) asks for consent once and the server actually enforces it for new clients.

L-CONSENT needs L-HOME, L-MONEY, L-TRACK and L-DATA live (consent hooks wrap save paths those lanes built, and the
Profile › Privacy & data section from L-DATA/wave 1 already exists to host the health rows).

## 5. Acceptance criteria (condensed)

- **UX-06** (L-PLAN2): AC0 a `Long run` weekday shows the run glyph, carb-led header text, and Friday's pre-run
  snack idea; setting a run day for the first time produces a change notice, not a silent target change; AC1
  barbell glyphs on exactly the planned weekdays; AC3 free user on a training day sees applied (bumped) targets and
  a working `Why?`; AC4 Refuel card offers two safety-filtered snacks, `Log it` works; AC5 week-glance shows all 7
  days at every text size.
- **UX-13** (L-PLAN2): AC1 sharing "What's left" with 42 of 87 unticked shares exactly those, grouped by aisle; AC2
  no emoji/markdown, pastes cleanly into WhatsApp/Keep; AC3 "Add this week's dinners" appends only planned dinners;
  AC4 button disabled on an empty list.
- **UX-26** (L-CONSENT): AC1 no health field stored before `Allow and save`, server rejects unconsented health
  writes; AC2 `Don't save it` stores nothing health-related; AC3 Withdraw deletes all listed data (owner + household)
  and records the withdrawal, plans stop showing `Checked for`; AC4 registration cannot complete without 16+
  confirmation (already true from wave 1, re-verify the server side); AC5 chat always carries the AI label, the AI
  chip renders on AI plan meals; AC6 counsel's checklist attached to the release PR before 9 Dec 2026.
