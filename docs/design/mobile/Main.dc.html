How to use this canvas

  1. Every board is one real screen or sheet, redrawn from apps/mobile, with its real copy. Pages group them: Auth, Food, Recipes & AI, Gym, Account.
  2. Boards marked interactive are linked. Press Play to tap through tabs, back buttons, rows and sheets like a prototype.
  3. Edit a board in place, or comment on it. Then ask an agent to implement the diff in apps/mobile, where each board's file name maps to a route.
  4. Token changes start on this board, then go to global.css, theme.ts and @chefer/tokens. Keep web parity per CLAUDE.md.
