How to use this canvas

  1. Each board is a real screen or sheet from master, drawn in the new shell with real copy. Pages group them by tab.
  2. Boards are linked. Press Play to tap through tabs, top-bar buttons, rows and sheets.
  3. Edit or comment on a board, then ask an agent to implement it in apps/mobile. Board names map to routes (see docs/design/mobile/README.md).
  4. Token changes start here, then go to color.ts + global.css (kept in sync by tests).
